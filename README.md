# Панель команд Windows 11

## [▶ ОТКРЫТЬ ПАНЕЛЬ](https://wadi-li.github.io/windows-startup-panel/)

16 команд для управления автозагрузкой, задержками запуска, службами и диагностики Windows. Поиск, подсказки, копирование команд, светлая и тёмная темы.

### Запуск кнопками

1. [Скачайте ZIP](https://github.com/wadi-li/windows-startup-panel/archive/refs/heads/main.zip) и распакуйте его.
2. Запустите `Install.cmd` под своим пользователем, без повышения прав.
3. Откройте панель онлайн или локальный `Windows_Startup_Panel.html`.
4. При запуске команды разрешите браузеру открыть Windows Startup Panel.

Браузер не запускает EXE и MSC напрямую. Установщик регистрирует локальный протокол `wadim-startup` для текущего пользователя. Обработчик принимает фиксированный список идентификаторов, без произвольных команд. Без установки доступно копирование команд для Win + R. Проверки SFC требуют подтверждения UAC.

Удаление: `Uninstall.cmd`. Настройки автозагрузки изменяются вручную в открываемых инструментах.

### Команды

| Команда | Назначение |
|---|---|
| `taskschd.msc` | Планировщик заданий и задержки запуска |
| `services.msc` | Службы и отложенный автозапуск |
| `taskmgr.exe` | Диспетчер задач и автозагрузка |
| `ms-settings:startupapps` | Параметры автозагрузки |
| `explorer.exe shell:startup` | Автозагрузка текущего пользователя |
| `explorer.exe shell:common startup` | Общая папка автозагрузки |
| `msconfig.exe` | Конфигурация системы |
| `eventvwr.msc` | Просмотр событий |
| `perfmon.exe /rel` | Монитор стабильности |
| `resmon.exe` | Монитор ресурсов |
| `msinfo32.exe` | Сведения о системе |
| `diskmgmt.msc` | Управление дисками |
| `devmgmt.msc` | Диспетчер устройств |
| `control.exe powercfg.cpl` | Электропитание |
| `sfc.exe /verifyonly` | Проверка системных файлов |
| `sfc.exe /scannow` | Проверка и восстановление файлов |

Проверены синтаксис JavaScript и соответствие команд обработчику. Запуск обработчика и UAC следует проверить на Windows.
