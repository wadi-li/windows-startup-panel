WINDOWS 11 · ЛОКАЛЬНЫЕ ИНСТРУМЕНТЫ

Панель запуска

Автозагрузка, задержки запуска и диагностика системы.

Первый запуск — установка один раз
  1. Распакуйте весь ZIP-архив в обычную папку.
  2. Запустите Install.cmd от своего пользователя. Права администратора для установки не нужны.
  3. Откроется эта панель. Нажмите «Запустить» и разрешите браузеру открыть Windows Startup Panel.

Обработчик устанавливается только для текущего пользователя и запускает фиксированный список команд. Произвольный ввод команд не поддерживается. Браузер может спрашивать разрешение при каждом запуске. Без установки работают поиск и копирование команд для Win + R. Удаление обработчика: Uninstall.cmd.

Как убрать или назначить задержку

Задание: taskschd.msc → Библиотека → нужное задание → Свойства → Триггеры → Изменить → «Отложить задачу на». Проверьте также вкладку «Условия».

Служба: services.msc → нужная служба → Свойства → Тип запуска → «Автоматически» / «Автоматически (отложенный запуск)».

Обычная программа: создайте задание с триггером «При входе в систему» и нужной задержкой. Для видимого окна выберите «Выполнять только для вошедшего в систему пользователя». Отключите прежнюю запись автозагрузки, чтобы избежать двух запусков.

Кнопки открывают инструменты управления. Параметры автозапуска вы меняете внутри них. Если программа медленно открывается вручную, причина обычно не в задержке автозагрузки.

Наведите указатель на кнопку для краткой подсказки. На телефоне описание видно под командой. Проверки SFC запрашивают права администратора и открывают отдельное окно с результатом.
