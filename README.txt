ПАНЕЛЬ ЗАПУСКА WINDOWS 11

1. Распакуйте весь архив (не запускайте установку прямо из ZIP).
2. Запустите Install.cmd обычным двойным щелчком от своего пользователя.
3. Откроется HTML-панель. Подтвердите открытие Windows Startup Panel в браузере.
4. Для повторного открытия используйте Windows_Startup_Panel.html из архива
   или установленную копию: %LOCALAPPDATA%\WadimStartupPanel\Windows_Startup_Panel.html

Для удаления обработчика запустите Uninstall.cmd под тем же пользователем.
Установка регистрирует протокол wadim-startup только в HKCU и копирует
два файла в %LOCALAPPDATA%\WadimStartupPanel. Службы и задания не создаются.
Политика выполнения PowerShell меняется только для отдельного процесса.
Обработчик принимает только перечисленные в коде идентификаторы команд.
Браузер может повторно запрашивать разрешение на открытие приложения.
В корпоративной Windows запуск PowerShell/обработчиков может быть запрещён.
Без обработчика можно копировать команды и запускать их через Win + R.
Для SFC нужны права администратора (например, открыть cmd.exe от администратора).
Панель не меняет автозагрузку автоматически: она открывает инструменты Windows.

Проверено: синтаксис JavaScript и соответствие 16 команд обработчику.
Визуальная проверка в Chromium заблокирована ограничениями среды. Выполнение команд,
UAC и установка в Windows требуют проверки на вашем компьютере.
